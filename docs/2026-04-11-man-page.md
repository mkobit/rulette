# rulette(1) -- the hermetic AI rule compiler

## SYNOPSIS

`rulette transform` [<options>] [<input>...]  
`rulette inspect` [<options>] [<input>...]  
`rulette schema` [<options>]  
`rulette init` [<options>] [<path>]

## DESCRIPTION

**Rulette** is a stateless, deterministic compiler for AI coding assistant configuration.
It normalizes diverse rules, skills, and tool configurations into a single, typed Intermediate Representation (IR) and emits them to any target format.

## COMMANDS

### transform

The primary workhorse for source-to-sink operations.

- `-o`, `--out` <path>:  
  Output path (file or directory) or multiple targets via `format:path`.
- `--to` <format>:  
  Target output format.
- `--filter` <expr>:  
  Keep only entities matching the expression.
- `--rename` <from=to>:  
  Rename a metadata field.
- `--set` <field=value>:  
  Set a metadata field.

### inspect

Pretty-print the IR or perform a dry-run emission analysis.

- `--to` <format>:  
  Analyze what survives emission to the target format.

### schema

Output the JSON Schema for the IR or a specific target.

## EXAMPLES

### Basic Transformation

Generate Claude skills from a rules directory:

    rulette transform ./rules/ --to claude --out .claude/skills/

### Multi-target Emission

Generate both Claude and Cursor rules in one pass:

    rulette transform ./rules/ \
      -o claude:.claude/skills/ \
      -o cursor-mdc:.cursor/rules/

### Unix Pipeline

Use `jq` to filter the IR before emitting:

    rulette transform ./rules/ | \
      jq '.entities |= map(select(.kind == "rule"))' | \
      rulette transform - --to cursor-mdc --out .cursor/rules/

## PHILOSOPHY

1. **Stateless**: No daemon, no hidden state.
2. **Deterministic**: Same input always produces same output.
3. **Hermetic**: Zero runtime dependencies.
4. **Strict Integrity**: Fails on identity collisions.
