# Rulette v0.1.0

Rulette v0.1.0 ships `rulette-v0.1.0-x86_64-unknown-linux-musl.tar.gz`.
It contains a fully static Linux binary with no runtime dependencies.
Verify the download with its `.sha256` sidecar before extracting `rulette`.

Rules, skills, primary instructions, and safe package resources form the narrow portability contract for Codex, OpenCode, Claude, Cursor, and Antigravity.
Agents, hooks, MCP settings, permissions, plugins, registries, and a fetch subsystem are outside both the portability and runtime contract.
Rulette has no registry and no fetch subsystem.

Lowering is strict by default.
Use `--allow-lossy` only after reviewing loss findings.

```text
rulette transform INPUT --target codex@project --project-root . --stage .rulette/stage
rulette transform --apply .rulette/stage/rulette.plan.json --expect-plan-sha256 SHA256 --allow-project-root .
```

`--stage` never publishes a live destination.
`--apply` is the only publishing operation and requires explicit root authorization and the expected plan digest.
